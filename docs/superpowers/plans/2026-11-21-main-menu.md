# Main Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. One implementer, one task reviewer, then final review.

**Goal:** Add a procedural Main Menu as the game's default scene, with Title → Main → Map Select panels and a headless test that proves the flow.

**Architecture:** `MainMenu` (`Node2D`) owns three `Panel`-based views and a selection index, reads input through the central InputMap actions, and exposes a pure `evaluate_menu(facts)` for headless assertions. `project.godot` main scene switches to it. No gameplay scene is edited.

**Tech Stack:** Godot 4.7.2 stable, GDScript, headless `--script` checks, PowerShell verifier.

**Spec:** `docs/superpowers/specs/2026-11-21-main-menu-design.md`

## Global Constraints

- Godot console: `D:\stu\gd\clone-game\tools\godot\Godot_v4.7.2-stable_win64_console.exe`; repo root; engine args before `--`.
- New files: `game/scenes/main_menu.tscn`, `game/scripts/main_menu.gd`, `game/tests/menu_check.gd` (+ `.uid`).
- Modify only: `game/project.godot` (`run/main_scene`), `tools/verify.ps1` (two additive lines), `game/README.md` (short run note), root `README.md` (one status line).
- Must not touch gameplay scenes/scripts, map data, canonical docs, milestone docs, input map definitions.
- No new input action; reuse `move_up/down`, `interact`, `attack`, `pause`.
- No new art/audio/font; procedural Labels/Panels matching existing HUD conventions.
- New Game requires two-step confirmation before `SaveState.clear()`.
- No milestone PASS, no art approval, no "fun" claim.

## Review Focus

- Input flow can fail: wrong panel / wrong scene path / unconfirmed save clear must be caught by named test cases.
- `project.godot` main scene actually points to the menu; all 14 existing scene smokes still work.
- Continue with no save cannot start a bogus run.
- Map Select lists all 10 entries with honest status labels.
- Back navigation and wrap-around.

**Files:** create the three new files; modify `game/project.godot`, `tools/verify.ps1`, `game/README.md`, `README.md`.

**Interfaces:**

- Produces: `[MENU] READY` on load; members `panel: String`, `selection: int`, `confirming_new_game: bool`; pure `evaluate_menu(facts: Dictionary) -> Array[String]`.

- [ ] **Step 1: Write `menu_check.gd` first** (`extends SceneTree`, ALL PASS/0-1, exact `EXPECTED_CASES`). Cases:
  1. fresh menu is on Title with selection 0;
  2. `interact` on Title → Main;
